# Қыз ұзату — онлайн-шақыру

Пригласительная страница на кыз узату с формой ответа гостей.
Ответы гостей падают в Google Таблицу.

**Адрес сайта:** https://alishmrk.github.io/wedding-invitation/

---

## Что нужно сделать — 3 шага

### Шаг 1. Вписать данные торжества

Открыть **`config.js`** и заменить значения. Вся страница собирается из этого файла.

Что важно знать про отдельные поля:

- **`dateISO`** — задаёт сразу и календарь, и обратный отсчёт. Формат строгий:
  `2026-10-16T18:00:00+05:00`, где `+05:00` — время Казахстана. Ошибётесь в формате —
  календарь и таймер пропадут, остальная страница уцелеет.
- **`dateText` / `timeText`** — как дата подписана словами, отдельно от `dateISO`.
- **`brideGen`** — имя невесты в родительном падеже («Алинаның ұзату тойына»).
  Оставите пустым — подставится имя + «ның», что не для всех имён верно.
- **`photo`** — вертикальное фото ~3:4 в папке `assets/`. Пустая строка — арка исчезнет.
- **`answers`** — варианты ответа. Текст уходит в таблицу дословно;
  `guests: true` означает «для этого варианта спросить количество гостей».

### Шаг 2. Подключить приём ответов

1. Создать пустую таблицу на [sheets.new](https://sheets.new), назвать например «Той — қонақтар».
2. Скопировать **ID таблицы** из её адреса — это часть между `/d/` и `/edit`:
   `docs.google.com/spreadsheets/d/`**`1AbC...XyZ`**`/edit`
3. В таблице: **Расширения → Apps Script**.
4. Удалить весь код в редакторе, вставить содержимое **`apps-script/Code.gs`**.
5. В первой строке заменить `'ВСТАВЬТЕ_ID_ТАБЛИЦЫ'` на свой ID.
6. Сверху выбрать функцию **`setup`** и нажать **Запустить**.
   Google попросит разрешение — «Разрешить». В таблице появится шапка.
7. **Развернуть → Новое развертывание → тип: Веб-приложение**:
   - Запуск от имени: **Я**
   - У кого есть доступ: **Все**  ← критично, иначе гости упрутся в экран входа Google
8. Скопировать выданный адрес (заканчивается на `/exec`) и вставить в `config.js` → `rsvpUrl`.

> Если позже правите `Code.gs` — нужно **Развернуть → Управление развертываниями →
> ✏️ → Версия: Новая → Развернуть**. Без этого сайт продолжит звать старую версию.

### Шаг 3. Опубликовать

```sh
git add -A
git commit -m "Шақыру"
git push -u origin main
```

Затем на GitHub: **Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save**.
Через 1–2 минуты сайт живой.

## Ссылки для гостей

Открыть **`links.html`** (локально или на сайте), вставить список имён по строке на гостя —
получите готовые персональные ссылки вида:

```
https://alishmrk.github.io/wedding-invitation/?g=Ерлан%20аға
```

Гость увидит «Құрметті Ерлан аға!», и его имя автоматически попадёт в таблицу вместе с ответом.
Там же кнопка **WhatsApp** — открывает чат с уже готовым текстом приглашения.

Ссылку можно отправить и без имени — тогда будет «Құрметті қонақтар!».

## Фото и музыка

**Фото.** Положить вертикальный снимок (~3:4) в `assets/` и вписать в `config.js`:

```js
photo: 'assets/bride.jpg',
```

Пока стоит заглушка `assets/bride.svg`. Фото показывается в арке на первом экране.

**Музыка.** Положить mp3 в `assets/` и вписать:

```js
music: 'assets/music.mp3',
```

Появится золотая кнопка «ӘУЕНДІ ҚОСУ». Автозапуска нет намеренно — браузеры его
блокируют, и звук без спроса раздражает. Оставьте `music: ''` — кнопки не будет.

## Локальная проверка

```sh
python3 -m http.server 8000
```

- `http://localhost:8000/` — приглашение
- `http://localhost:8000/?g=Ерлан%20аға` — с именем гостя
- `http://localhost:8000/links.html` — генератор ссылок

## Файлы

| Файл | Что это |
|---|---|
| `config.js` | **все данные торжества — единственный файл для правок** |
| `index.html` | разметка приглашения |
| `assets/style.css` | оформление |
| `assets/app.js` | имя гостя из ссылки, календарь, обратный отсчёт, отправка ответа, музыка |
| `assets/bride.svg` | заглушка фото — замените своим снимком |
| `links.html` | генератор персональных ссылок |
| `apps-script/Code.gs` | код для Google Apps Script |
| `.nojekyll` | чтобы GitHub Pages не пропускал файлы через Jekyll |

## Оформление

Стиль повторяет присланный шаблон: бордо `#7C1616` (тёмный `#640F0F`), золото `#E4AA5C`,
кремовая бумага `#F7F2E9`, рваные края между блоками.

Шрифты — **Cormorant Infant** (основной) и **Caveat** (рукописные акценты), оба с Google Fonts.
В шаблоне использовались лицензионные шрифты ASYLBEK и ROMUL, загруженные в Tilda;
их файлы в исходнике не отдаются, поэтому взяты открытые аналоги.

Важно при замене шрифтов: казахские буквы `ә ғ қ ң ө ұ ү һ` лежат в подмножестве
`cyrillic-ext`, а не в базовой кириллице. Многие рукописные шрифты его не содержат —
например, Marck Script их не имеет, и текст посыплется. Cormorant Infant и Caveat покрывают.
