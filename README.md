# Қыз ұзату — онлайн-шақыру

Пригласительная страница на кыз узату с кнопками **Келемін / Келе алмаймын**.
Ответы гостей падают в Google Таблицу.

**Адрес сайта:** https://alishmrk.github.io/wedding-invitation/

---

## Что нужно сделать — 3 шага

### Шаг 1. Вписать данные торжества

Открыть **`config.js`** и заменить значения: имя невесты, имена родителей, дату,
адрес заведения, ссылки на карты, телефоны. Больше ничего править не нужно —
вся страница собирается из этого файла.

### Шаг 2. Подключить приём ответов

1. Создать пустую таблицу на [sheets.new](https://sheets.new), назвать например «Той — қонақтар».
2. Скопировать **ID таблицы** из её адреса — это часть между `/d/` и `/edit`:
   `docs.google.com/spreadsheets/d/`**`1AbC...XyZ`**`/edit`
3. В таблице: **Расширения → Apps Script**.
4. Удалить весь код в редакторе, вставить содержимое **`apps-script/Code.gs`**.
5. В первой строке заменить `'ВСТАВЬТЕ_ID_ТАБЛИЦЫ'` на свой ID.
6. Сверху выбрать функцию **`setup`** и нажать **Запустить**.
   Google попросит разрешение — «Разрешить». В таблице появится шапка.
7. **Развернуть → Новое развертывание → тип: Веб-приложение**:
   - Запуск от имени: **Я**
   - У кого есть доступ: **Все**  ← критично, иначе гости упрутся в экран входа Google
8. Скопировать выданный адрес (заканчивается на `/exec`) и вставить в `config.js` → `rsvpUrl`.

> Если позже правите `Code.gs` — нужно **Развернуть → Управление развертываниями →
> ✏️ → Версия: Новая → Развернуть**. Без этого сайт продолжит звать старую версию.

### Шаг 3. Опубликовать

```sh
git add -A
git commit -m "Шақыру"
git push -u origin main
```

Затем на GitHub: **Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save**.
Через 1–2 минуты сайт живой.

## Ссылки для гостей

Открыть **`links.html`** (локально или на сайте), вставить список имён по строке на гостя —
получите готовые персональные ссылки вида:

```
https://alishmrk.github.io/wedding-invitation/?g=Ерлан%20аға
```

Гость увидит «Құрметті Ерлан аға!», и его имя автоматически попадёт в таблицу вместе с ответом.
Там же кнопка **WhatsApp** — открывает чат с уже готовым текстом приглашения.

Ссылку можно отправить и без имени — тогда будет «Құрметті қонақтар!».

## Музыка (по желанию)

Положить mp3 в `assets/` и вписать в `config.js`:

```js
music: 'assets/music.mp3',
```

Появится кнопка-нота в углу. Автозапуска нет намеренно — браузеры его блокируют,
и звук без спроса раздражает.
Оставьте `music: ''` — кнопки не будет.

---

## Локальная проверка

```sh
python3 -m http.server 8000
```

- `http://localhost:8000/` — приглашение
- `http://localhost:8000/?g=Ерлан%20аға` — с именем гостя
- `http://localhost:8000/links.html` — генератор ссылок

## Файлы

| Файл | Что это |
|---|---|
| `config.js` | **все данные торжества — единственный файл для правок** |
| `index.html` | разметка приглашения |
| `assets/style.css` | оформление |
| `assets/app.js` | имя гостя из ссылки, отправка ответа, музыка |
| `assets/ornament.svg` | орнамент қошқар мүйіз |
| `links.html` | генератор персональных ссылок |
| `apps-script/Code.gs` | код для Google Apps Script |
| `.nojekyll` | чтобы GitHub Pages не пропускал файлы через Jekyll |
